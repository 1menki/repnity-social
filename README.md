# repnity-social

Öffentliche Ablage für TikTok/Instagram-Slides von [Repnity](https://www.repnity.app).
Enthält nur fertige Bilder, die ohnehin veröffentlicht werden – keine Nutzerdaten, kein Code der App.

Fotos: [Pixabay](https://pixabay.com) (Pixabay-Inhaltslizenz, kommerzielle Nutzung erlaubt), Urheber pro Post in `credits.json`.
